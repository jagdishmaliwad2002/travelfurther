# 🌍 Travel Further - Premium Travel Agency UI

A modern, fully responsive, and visually stunning landing page designed for a premium travel agency. This UI features a sleek glassmorphism design, interactive components, and a seamless user experience across all devices.

## ✨ Features

*   **Hero Section:** Stunning background with a floating glassmorphism booking card and social proof.
*   **Destinations Grid:** Interactive cards showcasing popular travel spots with pricing and ratings.
*   **Exclusive Experiences:** Dark-themed section highlighting different travel categories.
*   **AI Trip Planner:** A clean, intuitive UI for users to plan their next trip.
*   **Special Offers:** Eye-catching promotional cards with discount badges.
*   **Testimonials:** Slider-style section for user reviews.
*   **Pricing Plans:** Three-tier pricing table highlighting the "Most Popular" plan.
*   **FAQ & Map Integration:** Accordion-style FAQs alongside a visual map section.
*   **Responsive Design:** Optimized for Desktop, Tablet, and Mobile devices.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure.
*   **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Glassmorphism effects (backdrop-filter), Transitions, and Media Queries.
*   **FontAwesome:** For scalable vector icons.
*   **Google Fonts:** Using the 'Poppins' font family for modern typography.
*   **Unsplash & UI Avatars:** For placeholder images and avatars.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser.
3. No build tools or dependencies are required!
